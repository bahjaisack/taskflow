# TaskFlow

A full-stack, production-ready task management application built with Next.js 15 App Router, Prisma ORM, MongoDB, and Auth.js v5.

---

## Features

- **Authentication:** Secure sign-in with Google and GitHub OAuth using Auth.js v5.
- **Kanban Task Board:** Drag-and-drop task organization across *Pending*, *In Progress*, and *Completed* states.
- **Full CRUD Operations:** Create, update, edit, and delete tasks with real-time UI feedback.
- **Modern UI/UX:** Styled using Tailwind CSS with dark mode support, custom modal dialogs, and skeleton loading states.
- **Type-Safe Backend:** Server Actions and Next.js 15 Route Handlers integrated with Prisma and MongoDB.

---

## Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Database & ORM:** MongoDB & [Prisma ORM](https://www.prisma.io/)
- **Authentication:** [Auth.js (NextAuth v5)](https://authjs.dev/)
